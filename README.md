# newyear-poll 🎆

เว็บโพลเลือกร้านและวันกินเลี้ยง ธีมปีใหม่ มีพลุ confetti และนับถอยหลัง
โฮสต์ฟรีบน GitHub Pages เก็บคะแนนโหวตใน Google Sheet ของคุณเอง

- ผู้โหวตใส่ชื่อ เลือกร้าน 1 ร้าน และวัน 1 วัน แก้โหวตของตัวเองได้
- ผลโหวตแสดงชื่อคนโหวตใต้แต่ละตัวเลือก และอัปเดตเองทุก 20 วินาที
- ไม่ต้องล็อกอิน ใครมีลิงก์ก็โหวตได้

## เอาไปใช้เอง (3 ขั้น)

1. กด **Use this template** (หรือ **Fork**) เพื่อคัดลอก repo นี้ไปที่บัญชีของคุณ
2. เปิด GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root → Save**
3. เปิดหน้า `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/setup.html` แล้วทำตามฟอร์ม

หน้า `setup.html` ให้กรอกชื่อโพล ร้าน และวันที่ในฟอร์ม พาตั้งค่า Google Sheet ทีละขั้น
แล้วสร้างเนื้อหา `config.js` ให้คัดลอกไปวางบน GitHub ไม่ต้องเขียนโค้ดเอง

## แก้ร้านและวันที่

วิธีง่ายที่สุดคือเปิดหน้า `setup.html` ของเว็บคุณ แก้ในฟอร์ม แล้ววางผลลัพธ์ทับ `config.js`

หรือแก้ `config.js` ตรง ๆ ก็ได้ ทุกอย่างอยู่ในไฟล์นี้ไฟล์เดียว:

```js
places: [
  { icon: "🍲", name: "ชื่อร้าน", detail: "ที่ตั้งหรือคำอธิบาย" },
],
allowOther: true,   // มีตัวเลือก "ร้านอื่น" ให้พิมพ์เอง

dates: [
  { day: "24", month: "ธ.ค.", weekday: "วันพฤหัสบดี 🎄" },
],
```

ถ้าเริ่มโพลรอบใหม่ ให้เปลี่ยน `pollId` (หน้า setup เปลี่ยนให้เองเมื่อแก้ตัวเลือก) และล้างแถวในชีต `votes`

> ผลโหวตจับคู่ด้วยชื่อร้านและวันที่ ถ้าแก้ชื่อหลังมีคนโหวตแล้ว คะแนนเดิมของตัวเลือกนั้นจะไม่ถูกนับ

## ต่อที่เก็บคะแนน (Google Sheet)

ทำครั้งเดียว ใช้เวลาประมาณ 3 นาที (หน้า `setup.html` มีขั้นตอนเดียวกันพร้อมปุ่มคัดลอกโค้ด)

1. สร้าง Google Sheet ใหม่ที่ [sheets.new](https://sheets.new)
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
4. กด **Deploy → New deployment** เลือกประเภท **Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด **Deploy** แล้วอนุญาตสิทธิ์ตามที่ Google ถาม
6. คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/`)
7. วางใน `config.js` ที่ `scriptUrl: "..."` แล้ว commit

คะแนนจะเข้าไปอยู่ในแท็บ `votes` ของชีต ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy เวอร์ชันใหม่ด้วย

ถ้ายังไม่ใส่ `scriptUrl` เว็บจะอยู่ในโหมดตัวอย่าง: กดโหวตได้ แต่ไม่ถูกบันทึกจริง

## ข้อจำกัด

- ไม่มีระบบล็อกอิน ระบุตัวคนโหวตจากเบราว์เซอร์ คนเดียวกันโหวตซ้ำได้ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์
- ใครมีลิงก์เว็บก็โหวตได้ เหมาะกับโพลในกลุ่มเพื่อนหรือทีม ไม่เหมาะกับการโหวตที่ต้องป้องกันการโกง
- รับได้สูงสุด 500 โหวต (แก้ `MAX_VOTES` ใน `Code.gs`)

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บ สไตล์ และอนิเมชัน |
| `setup.html` | ฟอร์มตั้งค่า สร้าง `config.js` ให้ |
| `config.js` | ร้าน วันที่ ข้อความ และ URL ที่เก็บคะแนน |
| `apps-script/Code.gs` | โค้ดฝั่ง Google Sheet |
