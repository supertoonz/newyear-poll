⚙️ ตั้งค่าโพล

กรอกฟอร์มนี้ แล้วคัดลอกผลลัพธ์ไปวางใน config.js ไม่ต้องเขียนโค้ดเอง

1รายละเอียดโพล

ข้อความหัวเว็บ ร้าน และวันที่ให้เลือก

2ที่เก็บคะแนน (Google Sheet)

ทำครั้งเดียว ประมาณ 3 นาที คะแนนจะอยู่ในชีตของคุณเอง

  1. เปิด sheets.new เพื่อสร้างชีตใหม่
  2. เมนู Extensions → Apps Script แล้วลบโค้ดเดิมออกทั้งหมด
  3. กดปุ่มด้านล่างเพื่อคัดลอกโค้ด แล้ววางลงไป
  4. Deploy → New deployment ประเภท Web app
    Execute as: Me · Who has access: Anyone
  5. กด Deploy อนุญาตสิทธิ์ แล้วคัดลอก Web app URL มาวางในช่องด้านล่าง

URL ควรขึ้นต้นด้วย https://script.google.com/ และลงท้ายด้วย /exec

3บันทึกลง config.js

คัดลอกข้อความด้านล่าง เปิด config.js บน GitHub ลบของเดิมทั้งหมด วางแทน แล้วกด Commit changes

เปิด config.js บน GitHub เพื่อวาง

หลัง commit รอ 1–2 นาที แล้วเปิด หน้าโพล อีกครั้ง
